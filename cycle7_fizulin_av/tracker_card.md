# Карточка для трекера

**Название:**

Проведение серии NR-V2X экспериментов в VaN3Twin, анализ результатов и подготовка отчета

**Описание:**

Подготовка воспроизводимого экспериментального блока в `VaN3Twin/ns-3` на основе сценария `v2v-emergencyVehicleAlert-nrv2x`: фиксация команд запуска, параметров и структуры сценария, проведение и систематизация серии из шести экспериментов по `NR-V2X Mode 2`, анализ сетевых, информационных и поведенческих метрик, а также отдельная верификация collision-сценария `v2v-degradation-collision-nrv2x`.

По итогам работы сформирован пакет материалов для команды: Notion-ready отчет, сводные CSV-таблицы, перечень ключевых сценариев репозитория и гайд по воспроизведению результатов. Материалы можно использовать как базу для следующего этапа сравнения `VaN3Twin/ns-3` с `Simu5G`.

**Трудозатраты:** `16 часов`
