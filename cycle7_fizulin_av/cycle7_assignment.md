## Физулин А.В. (VaN3Twin / ns-3 / NR-V2X / экспериментальная методика)

**Зона ответственности:** воспроизводимый экспериментальный блок в VaN3Twin/ns-3 для сценариев NR-V2X, систематизация результатов и подготовка итоговой документации

**Задачи:**

1. Формализовать и описать основной экспериментальный блок на базе `v2v-emergencyVehicleAlert-nrv2x`:
   - зафиксировать целевой сценарий, его прикладную логику и роль в исследовании
   - оформить матрицу из шести прогонов с варьированием параметров канала и penetration rate
2. Зафиксировать структуру запуска и воспроизводимость экспериментов:
   - описать сборку и запуск из корня репозитория
   - указать, какие файлы отвечают за карту, маршрут, конфигурацию SUMO и метрики
3. Систематизировать результаты по сетевым, информационным и поведенческим метрикам:
   - привести сводную таблицу по `PRR`, `latency`, `CAM from EV`, `inter-CAM gaps`
   - увязать CSV-артефакты с выводами по сценарию Emergency Vehicle Alert
4. Выполнить отдельную верификацию custom-сценария `v2v-degradation-collision-nrv2x`:
   - зафиксировать good-case и bad-case команды запуска
   - описать, при каких параметрах связь влияет на исход взаимодействия `veh8` и `veh6`
5. Подготовить пакет материалов для команды и отчет для Notion:
   - оформить карточку для трекера с описанием выполненной работы
   - собрать Notion-ready отчет, каталог ключевых сценариев репозитория и опись артефактов

**Результат на выходе:**

- воспроизводимый пакет команд для EVA- и collision-сценариев
- сводные CSV-артефакты и описание структуры выходных данных
- итоговый отчет для Notion по блоку `VaN3Twin / ns-3 / NR-V2X`
- каталог ключевых сценариев репозитория для дальнейшей работы и сравнения с Simu5G
