# Scenario Manager UI

## Обзор

Scenario Manager — локальный Web UI (Streamlit) для запуска исследовательских сценариев, просмотра результатов и быстрого перехода от параметров эксперимента к артефактам.

## Зачем нужен

Закрывает практическую проблему: многие сценарии уже runnable, но для их использования нужно помнить shell-команды, env-переменные, output-пути и структуру артефактов. Web UI делает этот слой удобным для демонстрации, повторного запуска и первичного анализа.

## Возможности

- Показывает описание сценария, научную цель и гипотезу
- Даёт форму для настройки параметров
- Запускает сценарий через его `run.sh`
- Потоково показывает лог выполнения
- Открывает summary CSV и generated plots
- Позволяет просматривать прошлые прогоны

## Запуск

```bash
# Из корня репозитория
tools/scenario_manager/launch.sh
```

По умолчанию интерфейс поднимается на `http://localhost:8501`.

Другой порт:
```bash
PORT=8502 tools/scenario_manager/launch.sh
```

## Структура модуля

| Файл | Описание |
|---|---|
| `app.py` | Streamlit-приложение и навигация по страницам UI |
| `scenarios.py` | Реестр доступных экспериментов, их параметров и метаданных |
| `runner.py` | Запуск сценариев и потоковая передача логов в UI |
| `visualizer.py` | Генерация summary-графиков и dashboards по артефактам |
| `run_*.sh` | Launcher-скрипты для sweep-сценариев |

## Доступные сценарии в UI

| Сценарий | Тип |
|---|---|
| `burst_vs_random_loss` | Sweep-сценарий |
| `density_scaling` | Sweep-сценарий |
| `latency_vs_loss_tradeoff` | Sweep-сценарий |
| `truck_lane_change` | Фиксированный доказательный кейс |
| `intersection_crash` | Фиксированный доказательный кейс |

## Результаты

Интерфейс работает с тем же слоем результатов, что и основной проект — данные сохраняются в стандартную директорию `~/NEWWAY_runs/` или `analysis/scenario_runs/`.
