# Структура репозитория

## Корневые директории

| Путь | Назначение |
|---|---|
| `src/` | Overlay поверх ns-3 / VaN3Twin: C++ модули симулятора. Изменять осторожно — живая ветка от upstream |
| `experiments/` | Все сценарии и эксперименты (каждый — самодостаточный пакет). См. [[Сценарии экспериментов]] |
| `runs/` | Evidence-прогоны по датам (YYYY-MM-DD). См. [[Evidence-прогоны]] |
| `tools/` | Генераторы графиков, analyzers, ВКР-сборка. См. [[Инструменты анализа]] |
| `reports/` | Учебные/рабочие отчёты (cycle7, scenario manager) |
| `conference/` | Финальные docx статей |
| `docs/` | Документация ns-3 upstream (rst) |
| `tests/` | Базовые тесты |
| `scripts/` | Operational helpers (sync overlay, docker run и т.п.) |
| `emulation-support/` | CARLA / OpenCDA вспомогательные файлы, V2X emulator |
| `docker/` | Dockerfile-ы. См. [[Docker]] |
| `img/` | Логотипы и диаграммы |
| `archive/` | ⚠️ Замороженные тексты ВКР, дубликаты, audit-история. **Не для ИИ** |

## Модули `src/`

| Модуль | Описание |
|---|---|
| `src/automotive/` | Основной модуль: CAM/DENM/CPM стек, EVA (Emergency Vehicle Alert), примеры |
| `src/sionna/` | Интеграция с NVIDIA Sionna: connection handler, серверные скрипты, сцены |
| `src/nr/` | 5G-LENA NR sidelink (Mode 2), PHY/MAC модели |
| `src/cv2x/` | C-V2X (LTE) стек |
| `src/traci/` | TraCI-интерфейс к SUMO |
| `src/traci-applications/` | Приложения поверх TraCI |
| `src/gps-tc/` | GPS и координатные утилиты |
| `src/carla/` | CARLA co-simulation модуль |
| `src/vehicle-visualizer/` | Визуализация транспортных средств |

## Корневые файлы

| Файл | Назначение |
|---|---|
| `README.md` | Описание проекта |
| `AGENTS.md` | Правила для ИИ-агентов |
| `CLAUDE.md` | Указатель на AGENTS.md |

## Куда что класть

| Что | Куда |
|---|---|
| Новый сценарий | `experiments/<name>/{scripts,docs,tools,results}/` |
| Новый прогон evidence | `runs/<YYYY-MM-DD>/<run_dir>/` |
| Новый аналитический скрипт | `tools/{plots,analysis,vkr}/` |
| Учебный/рабочий отчёт | `reports/<name>/` |
| Финальный docx статьи | `conference/` |
| Устаревшие/промежуточные файлы | `archive/<YYYY-MM-DD>/superseded/...` |

## Python-окружения

| Окружение | Назначение |
|---|---|
| `.venv/` | Основные скрипты (`tools/`, `experiments/*/tools/`) |
| `.venv_sionna/` | Sionna-зависимые скрипты |
| `.venv_docs/` | Генерация документации |

Создание основного окружения:
```bash
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
```
