# Установка и сборка

## Предварительные требования

- **ОС:** Ubuntu 20.04 / 22.04 (Ubuntu 24.04 **не** поддерживается официально)
- **SUMO:** версии от 1.6.0 до 1.18.0
- **Python:** 3.8+
- **C++ компилятор:** GCC с поддержкой C++17
- **GPU (опционально):** NVIDIA GPU + CUDA для Sionna ray-tracing

## 1. Установка SUMO

```bash
sudo add-apt-repository ppa:sumo/stable
sudo apt update && sudo apt install sumo sumo-tools sumo-doc
```

> ⚠️ Версии SUMO новее 1.18.0 могут ломать интеграции.

## 2. Клонирование репозитория

```bash
git clone https://github.com/AFETZ/1548-CAVISE2026_5GNR.git
cd 1548-CAVISE2026_5GNR
```

## 3. Bootstrap ns-3

> ⚠️ `sandbox_builder.sh` — **деструктивный** скрипт. Он создаёт `ns-3-dev` дерево, удаляет top-level файлы (включая `.git`) и удаляет себя. **Используйте disposable clone/workdir.**

Первый раз (с установкой зависимостей):
```bash
printf '\n' | ./sandbox_builder.sh install-dependencies
```

Последующие разы:
```bash
printf '\n' | ./sandbox_builder.sh
```

Или через Makefile:
```bash
make bootstrap-deps   # первый раз
make bootstrap        # последующие
```

## 4. Конфигурация ns-3

```bash
cd ns-3-dev
./ns3 configure --build-profile=optimized --enable-examples --enable-tests --disable-python --disable-werror
```

Или через Makefile (из корня):
```bash
make configure
```

## 5. Сборка

Минимальная (рекомендуется для первой проверки):
```bash
./ns3 build -j 2 v2v-simple-cam-exchange-80211p
```

Полная сборка (может занять длительное время):
```bash
./ns3 build -j 2
```

Через Makefile:
```bash
make build                                        # полная
make build BUILD_TARGET=v2v-simple-cam-exchange-80211p  # минимальная
```

## 6. Проверка

```bash
./ns3 run --no-build "v2v-simple-cam-exchange-80211p"
```

Или:
```bash
make run
```

## 7. Тестирование

```bash
./test.py --list                         # список тестов
./test.py --no-build --suite=<suite>     # запуск конкретного suite
```

> ⚠️ `./ns3 test` — **не работает** в этом дереве. Используйте `test.py`.

## 8. Python-окружения

```bash
# Основное окружение
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt

# Sionna-окружение (для GPU-скриптов)
python3 -m venv .venv_sionna && ./.venv_sionna/bin/pip install sionna
```

## Типичные проблемы

| Проблема | Решение |
|---|---|
| `./ns3: No such file or directory` | `ns3` появляется только после `sandbox_builder.sh` создаст `ns-3-dev` |
| `c++: fatal error: Killed signal terminated program cc1plus` | OOM при компиляции. Уменьшите jobs (`-j 1`) и/или добавьте swap |
| Несовместимость SUMO | Проверьте версию SUMO (1.6.0–1.18.0) |
| Ubuntu 24.04 | Официально не поддерживается |

## Makefile targets

```
make help            # список всех целей
make bootstrap       # sandbox bootstrap (деструктивный!)
make bootstrap-deps  # bootstrap + установка зависимостей
make configure       # конфигурация ns-3
make build           # сборка
make run             # запуск (RUN_TARGET=...)
make test-list       # список тестов
make test-suite      # запуск suite (TEST_SUITE=...)
```

Переменные:
- `JOBS=2` — число потоков компиляции
- `NS3_DIR=ns-3-dev` — путь к ns-3
- `BUILD_TARGET=` — конкретная цель сборки
- `RUN_TARGET=v2v-simple-cam-exchange-80211p` — что запускать
- `TEST_SUITE=` — какой test suite запускать
