# Инструменты анализа

Директория `tools/` содержит инструменты для постобработки, визуализации и генерации ВКР-артефактов. Все скрипты работают с `.venv/bin/python` (если не указано иное).

## Структура `tools/`

| Путь | Назначение |
|---|---|
| `tools/plots/` | Генераторы графиков и анимаций |
| `tools/analysis/` | Analyzers и aggregators |
| `tools/vkr/` | Генераторы ВКР: фигуры, сборка docx/pdf, bibliography |
| `tools/scenario_manager/` | Web UI для запуска/управления сценариями. См. [[Scenario Manager UI]] |
| `tools/results_pipeline/` | Пайплайн агрегации результатов |

## Графики (`tools/plots/`)

### Story-графики (дипломный стиль)
```bash
./.venv/bin/python tools/plots/build_valid_scenario_story_plots.py \
  --run-dir runs/2026-03-04/<run_dir>
```

### Интуитивные CSV-only графики
```bash
./.venv/bin/python tools/plots/build_valid_scenario_intuitive_plots.py \
  --run-dir runs/2026-03-04/<run_dir>
```

### Drop → decision timeline
```bash
./.venv/bin/python tools/plots/build_drop_decision_timeline.py \
  --run-dir runs/2026-03-04/<run_dir>
```

### Collision causality report
```bash
./.venv/bin/python tools/plots/build_collision_causality_report.py \
  --run-dir runs/2026-03-04/<run_dir>
```

### Intersection summary
```bash
./.venv/bin/python tools/plots/build_intersection_scenario_summary.py \
  --run-dir runs/2026-03-20/<run_dir>
```

### Compare tech summary
```bash
./.venv/bin/python tools/plots/build_compare_tech_summary.py \
  --run-dir <compare_tech_run>
```

### Sionna-визуализация
```bash
# 3D визуализация
./.venv/bin/python tools/plots/visualize_sionna_3d.py

# Анимация
./.venv/bin/python tools/plots/render_sionna_animation.py

# 5G PHY метрики
./.venv/bin/python tools/plots/plot_5g_phy_metrics.py
```

### Генерация всех графиков для прогона
```bash
./.venv/bin/python tools/plots/make_plots.py --run-dir <run_dir>
```

## ВКР-генераторы (`tools/vkr/`)

### Фигуры для глав
```bash

./.venv/bin/python tools/vkr/generate_chapter3_figures.py

# Фигура 2.1
./.venv/bin/python tools/vkr/generate_figure_2_1.py
```

### Сборка финального документа
```bash

./.venv/bin/python tools/vkr/build_final_vkr.py

```

```bash
./.venv/bin/python tools/vkr/generate_ieee_paper.py
```

## In-experiment tools

Некоторые сценарии имеют собственные инструменты в `experiments/<name>/tools/`. Они специфичны для одного сценария и не пересекаются с общими `tools/`.
