# NEWWAY Scenario Manager

Локальный Web UI для запуска исследовательских сценариев, просмотра результатов
и быстрого перехода от параметров эксперимента к артефактам.

## Зачем нужен

Инструмент закрывает практическую проблему исследовательской работы: многие
сценарии уже runnable, но для их использования обычно нужно помнить shell-команды,
env-переменные, output-пути и структуру артефактов. Web UI делает этот слой
более удобным для демонстрации, повторного запуска и первичного анализа.

## Что умеет

- показывает описание сценария, научную цель и гипотезу;
- дает форму для настройки параметров;
- запускает сценарий через его `run.sh`;
- потоково показывает лог выполнения;
- открывает summary CSV и generated plots;
- позволяет просматривать прошлые прогоны из `analysis/scenario_runs`.

## Как запустить

Из корня репозитория:

```bash
tools/scenario_manager/launch.sh
```

По умолчанию интерфейс поднимается на `http://localhost:8501`.

Если нужен другой порт:

```bash
PORT=8502 tools/scenario_manager/launch.sh
```

## Структура

- `app.py` — Streamlit-приложение и навигация по страницам UI
- `scenarios.py` — реестр доступных экспериментов, их параметров и метаданных
- `runner.py` — запуск сценариев и потоковая передача логов в UI
- `visualizer.py` — генерация summary-графиков и dashboards по артефактам
- `run_*.sh` — launcher-скрипты для sweep-сценариев

## Какие сценарии уже заведены в UI

- `burst_vs_random_loss`
- `density_scaling`
- `latency_vs_loss_tradeoff`
- `truck_lane_change`
- `intersection_crash`

Два последних — фиксированные доказательные кейсы, опирающиеся на пользовательские
сценарии из `my_scenarios/*`.

## Какой output ожидается

Интерфейс работает с тем же слоем результатов, что и основной проект:

- `*_summary.csv`
- `*-MSG.csv`
- `*-CTRL.csv`
- `*-PROFILE.csv`
- `collision_risk/*`
- предсгенерированные `PNG`

Для sweep-сценариев UI ориентируется на `OUT_BASE`, для фиксированных кейсов —
на `OUT_DIR`.

## Проверка

Базовые контракты покрыты unit-тестами:

```bash
python3 -m unittest tests.test_scenario_manager -v
```

Тесты проверяют:

- состав реестра сценариев;
- существование всех зарегистрированных `run.sh`;
- корректный выбор `OUT_BASE` / `OUT_DIR`;
- вызов callback в том же потоке, что и UI.

## Ограничения

- это локальный исследовательский интерфейс, а не production web-сервис;
- для полного UI-flow через browser automation в некоторых окружениях могут
  понадобиться дополнительные системные зависимости браузера;
- итоговая ценность UI зависит от качества самих артефактов сценария: если
  конкретный run не дал meaningful summary, UI это не исправит, а только покажет.
