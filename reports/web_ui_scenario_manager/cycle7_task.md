# Распределение задач на цикл №7

## Физулин А.В. (Web UI / запуск сценариев / результаты / воспроизводимость)

**Зона ответственности:** Web UI для запуска сценариев, просмотра результатов и снижения порога входа в экспериментальный контур проекта

**Задачи:**

1. Подготовить единый Web UI для запуска сценариев проекта:
   - выбрать легковесный локальный UI-стек
   - собрать единую точку входа для запуска и просмотра результатов
2. Оформить реестр сценариев и параметров:
   - научная цель и гипотеза каждого сценария
   - набор настраиваемых параметров
   - ожидаемые артефакты
3. Связать UI с реальными сценарными launcher-скриптами:
   - sweep-сценарии
   - фиксированные пользовательские кейсы
   - поддержка `OUT_BASE` / `OUT_DIR`
4. Реализовать просмотр результатов:
   - summary CSV
   - generated plots
   - browse past runs
5. Подготовить документацию и минимальный тестовый контур:
   - README по запуску UI
   - проверка реестра сценариев и сценарных контрактов

**Результат на выходе:**

- работающий локальный Web UI на базе `Streamlit`
- единый реестр из 5 сценариев
- запуск сценариев из интерфейса
- просмотр summary-результатов и графиков
- README и базовые unit-тесты

**Оценка затраченных часов:** `18 ч`
