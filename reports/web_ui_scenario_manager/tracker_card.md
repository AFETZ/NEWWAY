# Разработка Web UI для запуска сценариев и просмотра результатов

Подготовлен отдельный локальный Web UI для запуска сценариев, просмотра summary
CSV, generated plots и прошлых прогонов.

Выполненные блоки работ:

- собран Streamlit-интерфейс для сценариев проекта
- оформлен реестр из 5 сценариев с научными целями, гипотезами и параметрами
- реализована интеграция с launcher-скриптами и output-директориями
- добавлены страницы описания, конфигурации и запуска, просмотра результатов и просмотра прошлых запусков
- подключены статические и интерактивные визуализации
- добавлены базовые unit-тесты и README

Ключевой результат:

- у проекта появился не просто набор shell-команд, а единая рабочая точка входа
  для сценариев и их результатов
